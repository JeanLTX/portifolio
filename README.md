# Portfólio - Jean Lucca

Bem-vindo ao repositório do meu portfólio pessoal! Este projeto foi desenvolvido para apresentar minhas habilidades, projetos e experiência como Desenvolvedor Front-End.

🔗 **Acesse o projeto online:** [Visualizar Portfólio](https://jeanltx.github.io/portifolio/)

## 🛠 Tecnologias Utilizadas

*   **HTML5** (Semântico e Acessível)
*   **CSS3** (Animações, Flexbox, Grid, Glassmorphism)
*   **Tailwind CSS** (Framework CSS)
*   **JavaScript** (Interatividade e Lógica)
*   **jQuery** (Plugins e manipulação de DOM)

## ✨ Funcionalidades

*   **Design Responsivo:** Adaptado para Mobile, Tablet e Desktop.
*   **Animações:** Efeitos de digitação, scroll suave, pássaros voando (Canvas) e estrelas cadentes.
*   **Formulário de Contato:** Integração direta com WhatsApp.
*   **Carrossel de Projetos:** Visualização interativa dos trabalhos realizados com loop infinito.

## 🚀 Como rodar localmente

1.  Clone o repositório:
    ```bash
    git clone https://github.com/JeanLTX/portifolio.git
    ```
2.  Abra a pasta do projeto.
3.  Abra o arquivo `index.html` no seu navegador.
